# AI Solutions Lisboa - Landing Page

Uma landing page moderna e responsiva para serviços de inteligência artificial e automação direcionados a pequenas empresas em Lisboa.

## 🚀 Características

- **Design Moderno**: Interface limpa e profissional com gradientes e animações suaves
- **Totalmente Responsivo**: Adaptado para todos os dispositivos (desktop, tablet, mobile)
- **Otimizado para SEO**: Meta tags, títulos e estrutura otimizada para motores de busca
- **Animações Suaves**: Transições e efeitos visuais que melhoram a experiência do utilizador
- **Localizado para Portugal**: Conteúdo em português adaptado ao mercado lisboeta
- **Call-to-Actions Claros**: Botões e links estrategicamente posicionados para conversão

## 🚀 Como Usar

1. **Abrir a página**: Simplesmente abra o ficheiro `index.html` num navegador web
2. **Personalizar conteúdo**: Edite o texto, imagens e informações de contacto
3. **Actualizar contactos**: Altere os links de email e telefone na secção de contacto
4. **Adicionar analytics**: Insira o código do Google Analytics se necessário
